Python示例在Python3.12.3、macOS27.0.1 arm64运行验证。安装依赖时使用虚拟环境；不需要API Key，不调用付费服务。不包含公众号发布配置或账号凭据。

代码用于学习与复现文中实验，具体结果以各目录的说明为准；合成数据不能冒充模型推理结果，二维码样本也不能当成隐私安全的通用测试。
