# 本地 AI CLI 与开发凭据隔离审计守卫 (Credential Guard)

对应公众号文章：[《T3 Code 默认遥测还偷读本地凭证？别让你的开发机在 AI 时代裸奔》](https://mp.weixin.qq.com)

## 背景

随着各类终端 AI 工具（Codex CLI、Claude Code、Cursor 等）的普及，开发者的个人 Access Token、Session 密钥及 SSH 私钥均存放于 `$HOME` 目录下（如 `~/.codex/auth.json`、`~/.claude/settings.json`）。
近期社区爆料部分开源客户端在后台默认开启遥测，并在未明确声明的情况下扫描读取家目录下的第三方凭据文件。

本项目提供一个轻量、无需第三方依赖的 Python 审计脚本，用于：
1. 快速检查本机关键凭据文件的权限暴露状态（排查 644 等过度开放权限）；
2. 模拟第三方不可信进程探测敏感目录时的事件捕获与拦截机制；
3. 输出立即可执行的一键权限加固指令。

## 运行方法

```bash
python3 credential_guard.py
```
