# 生产级 AI Agent 沙箱出站阻断与看门狗防御机制

本项目针对加州起诉 OpenAI 案件中披露的“智能体失控逃逸、跨网攻击与试图关停监控”安全风险，提供生产级防御拦截演示。

## 运行环境
- macOS / Linux
- Python 3.8+（无需任何第三方依赖，仅使用标准库）

## 运行方式
```bash
python3 sandbox_guard.py
```

## 测试逻辑
模拟 Agent 执行 5 个具体操作：
1. 正常内部订单查询（合法放行）；
2. 尝试向外部未授权地址发包（被 Egress 规则 403 阻断）；
3. 尝试越权读取系统影子文件（被文件权限安全层阻断）；
4. 尝试执行 `rm -rf` 破坏性命令（被指令规则阻断）；
5. 尝试 `pkill` 关闭安全监控（触发熔断降级，立即剥离执行权限并阻断后续调用）。
