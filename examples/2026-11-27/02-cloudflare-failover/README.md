# 02-cloudflare-failover

> 公众号 2026-11-27 科技次条文章示例代码：微服务 CI/CD 发布流水线针对第三方云控制面 API 的超时熔断与旁路降级网关。

## 背景痛点

2026-11-27 凌晨 Cloudflare 控制台与核心管理 API 遭遇大面积瘫痪，虽然边缘 CDN 仍正常转发，但大量依赖 Cloudflare API 刷新缓存、切换 DNS 记录的自动化发布脚本全部超时死锁，导致生产发布回滚失败。

## 核心设计

1. **控制面与数据面解耦**：第三方 SaaS 的管理 API 可用性天然低于边缘转发，不能作为 CI/CD 发布的硬阻断依赖。
2. **主动熔断（Circuit Breaker）**：设置 2.5 秒超时上限，一旦发现外部 API 出现 504 或无响应，立刻熔断退出。
3. **旁路降级三部曲**：
   - 静态资源 URL 强化 Hash 版本化，天然免疫 CDN 旧缓存；
   - 内部网关广播 Cache-Control 驱逐；
   - 将外部刷新请求推入异步补偿队列，待网络自愈后重试。

## 运行方式

无需任何第三方依赖，直接运行：

```bash
python3 cloudflare_api_failover.py
```
