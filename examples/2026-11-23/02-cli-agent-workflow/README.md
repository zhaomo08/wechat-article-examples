# 终端智能体 (CLI Agent) 实战防翻车守护器

针对开发者从传统 IDE 转向终端智能体（如 Claude Code、Codex 等）过程中遇到的典型痛点：长上下文导致 Token 暴涨、误改关键系统配置与凭证、测试未通过的假完成。

## 场景痛点
1. 对话不断拉长，Token 消耗呈指数级膨胀；
2. 终端 Agent 意外改动敏感凭据（如 `.env`）或关键依赖；
3. 智能体宣称“已成功修复”，但本地单元测试实际未通过。

## 运行方式
```bash
python3 cli_agent_guard.py
```

## 核心机制
- 实时上下文预算健康度监控；
- 受保护文件写入阻断机制；
- 测试状态机严格校验。
